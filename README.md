# 花屋のかんたん電卓

花の単価をタップするだけで、本数・合計・内訳を計算するスマホ向けの電卓です。

## できること

- 50 / 100 / 150 / 200 / 250 / 300 / 400 / 500 円ボタン
- 1,000 / 2,000 / 3,000 円ボタン
- 価格別の本数と内訳表示
- 1つ戻す・全消去
- 売上確定後の入力内訳履歴
- 合計コピー

## 使い方

`index.html` をブラウザで開けば使えます。履歴は各端末のブラウザ内に保存されます。

公開中アプリ: https://florist-calculator.navy-hen-9250.chatgpt.site
